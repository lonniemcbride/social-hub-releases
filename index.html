Getting started

  1. Download and run the installer above. It installs to your user folder, so no admin password is needed.
  2. Windows may show a blue "Windows protected your PC" screen. That's expected for a new app like this one — click More info, then Run anyway.
  3. Sign up in the app with the email address your invite was sent to.
  4. Enter your invite code (from the invite email) on the "Join a project" screen — or just click the link in that email if you already have the app installed.
Why the security warning? The installer isn't yet signed with a paid code-signing certificate, so Windows flags it as unrecognized. The app itself is safe — this is standard for small, newly-published software.
Having trouble? Reach out to whoever invited you.

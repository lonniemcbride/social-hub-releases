# Cornerstone — Releases

Compiled installers for Cornerstone (Windows NSIS + macOS universal dmg/zip).
No source code lives in this repo.

- **Download page:** https://lonniemcbride.github.io/social-hub-releases/
- **Raw assets:** see the Releases tab.

This repo is public because `electron-updater`'s GitHub provider can't read
release assets from a private repo without a per-user token, which would
break silent background updates for installed copies.
